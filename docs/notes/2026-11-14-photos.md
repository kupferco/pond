# Photos page

`/photos` shows photos of earlier builds. Source of truth: the Drive folder **Pond photos**. A sync copies
them into Cloud Storage (bucket of project `pond-grow`, folder `photos/`), not into git:
`photos/web/<driveId>.jpg` (max 1600 px), `photos/thumb/<driveId>.jpg` (max 400 px), `photos/index.json`.

- Idempotent: a file is skipped when its Drive id and modified time are unchanged. Files deleted from the folder are removed from the bucket on the next sync. Renamed files and edited descriptions update without re-copying.
- Taken date comes from the photo's EXIF time (falls back to the Drive creation time); newest first. Caption = the Drive file description.
- Viewing is open, like the Drawings gallery (`storage.rules` allows read on `photos/`). Writing is only possible with the service account.
- Sync: `cd control-ui && npm ci && GOOGLE_APPLICATION_CREDENTIALS=key.json node scripts/sync-photos.mjs` (add `DRY_RUN=1` to preview), or the GitHub Action **Sync photos** (Actions tab, Run workflow). There is no button on the page: the site has no login, so an admin-only button would have nothing to check.

## Dani: manual steps (once)

1. In Google Cloud console, project `pond-grow`: enable the **Google Drive API**.
2. Use the service account already behind the GitHub secret `FIREBASE_SERVICE_ACCOUNT_POND_CONTROL` (or make a new one and store its JSON key in that secret). It needs the role **Storage Object Admin** on the bucket. Copy its email (`...@pond-grow.iam.gserviceaccount.com`).
3. Add `github-deployer@pond-grow.iam.gserviceaccount.com` (the service account) as **Viewer** to the Pond shared drive (Drive → Shared drives → Pond → Manage members), or to the folder **Pond photos** only. My Drive folders shared with it work too. If several folders are named "Pond photos", set `PHOTOS_FOLDER_ID` (and optionally `PHOTOS_DRIVE_ID`).
4. Allow the site to read the photo list from the browser: `gcloud storage buckets update gs://pond-grow.firebasestorage.app --cors-file=control-ui/photos-cors.json`.
5. Deploy the storage rules: `cd control-ui && firebase deploy --only storage`.
6. Check the bucket name in the Firebase console (Storage). If it is not `pond-grow.firebasestorage.app`, change `BUCKET` in `docs/photos/index.html`, the default in `scripts/sync-photos.mjs`, and step 4.

Then: save photos into the folder, run **Sync photos**, open `/photos`.
